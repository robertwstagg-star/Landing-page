# TrekStak Get — Creator download landing

Landing page for `https://get.trekstakapp.com`.

Built for Instagram / creator bios: show a personal promo code, then send fans to the App Store (with in-app browser workarounds).

## URL examples

- `https://get.trekstakapp.com/?code=MAYA20`
- `https://get.trekstakapp.com/MAYA20`

## Publish

Host these files on GitHub Pages (or similar) with the `CNAME` pointing at `get.trekstakapp.com`, then add the DNS CNAME at your domain provider.
